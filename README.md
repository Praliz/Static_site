# Static
Static website for boot.dev course

It can esentially be used by anyone, who wish to build a static site. just change the CSS if the style dosent match you and write the desired contents in Markdown (into the contents folder ofc).
run the build.sh and watch my magic :) 

I did not invent a static website builder... but going though the motions is rewarding and most of the course was "build your own unit tests to check the logic".
So i challenge the user to try and break my generator :)
